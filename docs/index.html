Supplied worlds.

One to sixteen explicit worlds, one to three agents, up to five atoms, six queries and four sequential public updates. Formulas have depth at most six and at most 128 total supplied syntax nodes. Every agent starts with a complete S5 equivalence partition. No private announcements, probability, belief revision, event models, planning or strategic reasoning.

An update keeps exactly the worlds where its content was true before the announcement. A removed focus is marked eliminated, with null query values, never false or vacuously known.
