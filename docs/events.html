METHOD / SMALL, FACTUAL, QUALIFIED

        
Uncertain is not mistaken.

        

          Both world and event relations are supplied S5 equivalence partitions.
          The product intersects the component relations on
          precondition-satisfying pairs; atomic valuations are inherited from
          the original world. This preserves S5 on every nonempty product. The
          designated pair must separately exist for an executable pointed
          update.
        

        

          This can represent an observed read or uncertainty about whether a
          read happened. It does not represent a fully unnoticed secret where an
          outsider falsely rules out the actual event. That requires a
          different, non-S5 event relation. No postconditions, factual change,
          probabilities, belief revision, action composition, nested dynamic
          operators, event synthesis or planning are implemented.
        

        

          The generator crosses partition blocks and reuses the existing
          pointwise knowledge engine. A separate checker reconstructs the full
          product from component relation tests and row classes, then uses the
          existing independent truth-set/Floyd oracle. The browser uses
          union-find on the pair relation and its separately written modal
          engine. Shared schema and written semantics are disclosed. Optional
          actual pyModelChecking compares the reconstructed modal truth sets
          using ordinary CTL AX/AG; it is not an independent event parser or a
          proof.
        

        

          Established dynamic epistemic logic, original bounded implementation
          and fixtures. Not new theory, a scalable symbolic solver, private
          data, inferred human beliefs or a guarantee about real agents.
